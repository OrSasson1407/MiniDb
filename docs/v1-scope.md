# הגדרת גרסה 1.0

גרסה 1.0 היא הגרסה הראשונה שאפשר לסמוך עליה לנתונים אמיתיים בתוך אפליקציית .NET. הרשימה כאן קובעת מה נכנס ומה לא. מה שלא מופיע ב"נכנס" לא מובטח, גם אם הוא קיים בקוד.

## נכנס לגרסה 1.0

**אמינות**
- כל commit שאושר שורד הרגת תהליך בכל נקודה. אומת בבדיקות קריסה.
- כל דף נבדק ב-checksum. קובץ פגום נדחה עם שגיאה ברורה, לא נקרא בשקט.
- כשהקובץ נפתח מחדש, השחזור מה-WAL מחזיר בדיוק את הטרנזקציות שאושרו.

**נתונים ומנוע**
- טבלאות עם מפתח ראשי `BIGINT`, וטיפוסים `INT`, `BIGINT`, `DOUBLE`, `BOOL`, `VARCHAR(n)`.
- `NULL` עם סמנטיקה מלאה.
- רשומות גדולות מדף אחד, עם דפי overflow.
- אינדקסים משניים על `INT`, `BIGINT` ו-`VARCHAR`.
- VACUUM שמשחרר מקום אחרי מחיקות.

**SQL**
- `SELECT` עם `WHERE` (AND, OR, סוגריים, `IN`, `BETWEEN`, `LIKE`, `!=`), `ORDER BY`, `LIMIT`, `DISTINCT`.
- `INNER JOIN` ו-`LEFT JOIN`, `GROUP BY` עם `HAVING`, ואגרגטים `COUNT`, `SUM`, `MIN`, `MAX`, `AVG`.
- `INSERT`, `UPDATE`, `DELETE`, עם WHERE חובה ב-`UPDATE` וב-`DELETE`.
- `CREATE TABLE` עם `NOT NULL`, `UNIQUE`, `DEFAULT`, ו-`PRIMARY KEY`.
- פרמטרים לשאילתות (`@name`).
- `EXPLAIN`.

**מקביליות**
- קוראים לא נחסמים על כותב (snapshot).
- כותבים מקביליים משתפים fsync דרך group commit.

**ממשקים**
- API בקוד C#.
- ספק ADO.NET (`DbConnection`, `DbCommand`, `DbDataReader`, `DbParameter`).
- שרת רשת עם פרוטוקול בינארי מגורסן, אימות משתמש וסיסמה, ו-TLS.
- חבילת NuGet.
- `MiniDb.Cli`.

**תפעול**
- גיבוי online בלי לעצור כתיבה, ושחזור מגיבוי.
- מדדים בסיסיים ו-slow query log.
- ייבוא וייצוא CSV ו-JSON.

**תיעוד ואיכות**
- README עם התחלה מהירה, דוגמאות, ורשימת מגבלות.
- benchmarks שאפשר לשחזר עם סקריפט אחד.
- CI שרץ על כל שינוי.
- ביקורת חיצונית לפחות אחת.

## לא נכנס לגרסה 1.0

נדחה לגרסאות עתידיות, ומופיע ב-README כמגבלה:

- **הצפנה במנוחה ושליטה בהרשאות מפורטת לכל טבלה:** אימות משתמש וסיסמה נכלל, אבל לא ניהול הרשאות לטבלה.
- **CTE (`WITH`) ותתי-שאילתות מורכבות:** תתי-שאילתות פשוטות (`IN (SELECT ...)`) נכללות.
- **אופטימיזציה מתקדמת של סדר JOIN:** בחירת סדר בסיסית לפי גודל טבלה נכללת, אבל לא סטטיסטיקות מלאות.
- **מסדי נתונים מרובים בקובץ אחד, ו-triggers, ו-views:** לא נתמכים.
- **שינוי סכמה אחרי יצירה** (`ALTER TABLE`): לא נתמך. נדרש ליצור טבלה מחדש.
- **אינדקסים מרחביים, JSON, ומערכי נתונים גדולים מאוד** (מעל כמה מאות GB): לא נבדקו.

## קריטריונים לסגירת 1.0

1. כל התנאים של שלבים 0–7 בתוכנית העבודה מתקיימים.
2. בדיקות הקריסה רצו מיליון הרגות בלי אובדן commit מאושר.
3. אין באגים פתוחים מסוג "אובדן נתונים" או "קובץ פגום בשקט".
4. כל מגבלה ברשימת "לא נכנס" מופיעה ב-README, ולא רק כאן.
5. הביקורת החיצונית נסגרה.
